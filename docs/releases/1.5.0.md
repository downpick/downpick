# Downpick 1.5.0

## What's new

- **Search AI chat history:** find saved conversations by title, message text, or SQL from the search field in AI history. Search is case-insensitive and works across paginated results.
- **Spot failed queries in tabs:** query tabs now display an error icon when the last query failed. Hover over the icon to see the error message.

## Improvements and fixes

- **Load indexes on demand:** PostgreSQL and SQL Server table indexes now load when you expand a table, avoiding index queries for every table during initial schema loading. Failed index requests can be retried. Expand a table before searching for its indexes by name.
- **More predictable explorer search:** searching connections expands only the paths needed to reveal matching results. You can collapse branches while searching, and clearing the search restores the previous tree expansion state.
- **Clearer connection errors:** unreachable PostgreSQL and SQL Server errors now include network, VPN, and firewall guidance. On macOS, they also explain how to check Downpick's Local Network permission; the app now includes a local-network usage description.

## Downloads and installation

- **macOS Apple Silicon:** choose `Downpick-1.5.0-arm64.dmg`.
- **macOS Intel:** choose `Downpick-1.5.0.dmg`.
- **Windows x64:** choose `Downpick Setup 1.5.0.exe`.
- **Linux x64:** choose `Downpick-1.5.0.AppImage` and make it executable before launching.
- Verify downloads against the attached `SHA256SUMS.txt`. macOS ZIP files, blockmaps, and update manifests are also attached for the updater.

macOS signing and notarization depend on the credentials configured for this build. Without Apple signing credentials, macOS packages use ad-hoc signing and require manual updates; Gatekeeper may require explicit approval on first launch. Verify the build's signing status before publishing the draft.
