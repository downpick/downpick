# Downpick 1.4.0

## What's new

- **Browse table indexes:** PostgreSQL and SQL Server tables now show an Indexes group in the explorer, including index types and primary-key/unique indicators. Search indexes by name and copy their creation SQL when available.
- **Copy results as JSON:** use the JSON button in the result bar to copy query results as formatted JSON. Nested values and nulls are preserved, MongoDB results retain their document structure, and duplicate or unnamed SQL columns receive distinct keys.
- **Browse functions and procedures:** enable **Show functions and procedures** in Settings to explore PostgreSQL and SQL Server routines. Double-click a routine to open its SQL definition in an editor tab, including individual PostgreSQL overloads.
- **Advanced connection options:** PostgreSQL and SQL Server profiles now support an initial database, explicit TLS modes, and a custom PEM CA bundle. PostgreSQL Amazon RDS endpoints use verified TLS with bundled RDS certificates in Default mode.

## Improvements

- Connection errors now provide clearer guidance for certificate validation failures, TLS negotiation problems, and PostgreSQL servers that reject unencrypted connections.
- Connection profiles preserve the new database and TLS settings across saving, vault unlocking, connection tests, and database selection.

## Downloads and installation

- **macOS Apple Silicon:** choose `Downpick-1.4.0-arm64.dmg`.
- **macOS Intel:** choose `Downpick-1.4.0.dmg`.
- **Windows x64:** choose `Downpick Setup 1.4.0.exe`.
- **Linux x64:** choose `Downpick-1.4.0.AppImage` and make it executable before launching.
- Verify downloads against the attached `SHA256SUMS.txt`. macOS ZIP files and update manifests are also attached for the updater.

macOS signing and notarization depend on the credentials configured for this build. Without Apple signing credentials, macOS packages use ad-hoc signing and require manual updates; Gatekeeper may require explicit approval on first launch. Verify the build's signing status before publishing the draft.
